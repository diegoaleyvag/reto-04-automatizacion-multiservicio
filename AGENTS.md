# Reglas del repositorio

- Mantener el código sin comentarios en JavaScript, HTML, CSS, SQL, Docker, YAML y scripts.
- Escribir los commits, README y manuales en español.
- Los identificadores pueden seguir las convenciones normales de cada lenguaje, también en inglés.
- No añadir firmas ni trailers de coautor a los commits.
- Mantener el arranque con Docker Compose y los comandos Make reproducibles.
- Validar cambios con las pruebas funcionales e indicar solamente verificaciones realmente ejecutadas.
- No guardar credenciales privadas, archivos .env, datos de ejecución ni respaldos en Git.
- Mantener consultas parametrizadas, validación del servidor y errores seguros.
